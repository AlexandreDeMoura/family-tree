# Family Tree web

React/Vite starter with Tailwind CSS, React Router, and TanStack Query. React Flow
and ELK.js are installed for the later tree renderer. The current page is a shell;
organizer sign-in, editing, and family browsing follow in the PRD commit plan.

Use the workspace commands in the [root README](../../README.md) and the
[setup guide](../../SETUP.md). Browser Supabase usage is reserved for Auth and
signed uploads; family data will go through Fastify. UI QA is manual.
